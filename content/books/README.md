# كتب المصدر 2

هنا توضع ملفات تعريف الكتب المرفوعة يدويًا (JSON لكل كتاب).
ملفات PDF نفسها لا تُرفع على GitHub — ستُخزن في التخزين السحابي (Cloudflare R2) في مرحلة Vercel.

مثال `book-001.json`:
```json
{
  "id": "book-001",
  "title_ar": "شرح نظام المعاملات المدنية",
  "tags": ["معاملات مدنية", "شرح", "فقه قانوني"],
  "pdf_url": "https://pub-xxxx.r2.dev/books/book-001.pdf",
  "added_at": "2026-07-11"
}
```
